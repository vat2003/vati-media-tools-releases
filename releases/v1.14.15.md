# VATI Media Tools v1.14.15 — VPS Loop: 2 link song song và tự chọn ổ

## Tính năng

- Chọn **1 hoặc 2 link xử lý đồng thời** trong VPS Agent (mặc định 2). Mỗi job có tiến độ và hủy riêng; các link còn lại xếp hàng FIFO.
- **Tự chọn ổ đủ dung lượng** cho file tạm và kết quả, tính cả phần dung lượng job khác chưa ghi. Kiểm tra quyền ghi và chọn lại ổ output sau tải/probe nguồn. Cache và output có thể ở các ổ khác nhau.
- **Không dùng các ổ**, ví dụ `N, E`, cấu hình trong Tool và cho đợt gửi từ Web. Web không thể cho phép lại ổ Tool đã cấm. Chọn ổ output cụ thể sẽ không âm thầm chuyển ổ.
- Thư mục output riêng theo job ID tránh xung đột nguồn trùng tên. Tự dọn vẫn chỉ hoạt động khi bật và bảo vệ file của cả hai job.
- Giữ fix Transfer.it retry của v1.14.14; không thay đổi chất lượng Xóa Logo, Upscale, AI Local hay Live Converter.

## Nâng cấp và sử dụng

1. Dừng batch/agent và đóng app cũ trước khi cài **trên VPS đang chạy agent**. Giữ URL/token; khởi động lại app hoặc scheduled task sau cập nhật.
2. Tool → VPS Agent: chọn **2 link song song**, nhập **Không dùng các ổ** (ví dụ `N`). Để trống thư mục tạm để tự chọn. Lưu và bật agent.
3. Web → [VPS Loop](https://www.vota.work/vps-loop): chọn **Tự chọn ổ đủ dung lượng** và gửi các link.
4. Companion website cần migration `20261030120000_loop_parallel_auto_drives.sql` và API mới. Agent cũ giữ chế độ tuần tự và không nhận job có quy tắc loại trừ mà nó không hỗ trợ.

Không có ổ phù hợp thì job báo lỗi, không fallback vào ổ bị cấm. Tự chọn ổ không tự bật xóa file cũ. Hai link song song không bảo đảm tốc độ gấp đôi vì phụ thuộc mạng và I/O ổ đĩa.
