# VATI Media Tools v1.14.21 — VPS Agent efficient sync

## Thay đổi

- Giảm request nhận job rỗng khi heartbeat xác nhận đồng bộ mới và còn khỏe. Mất kết nối/server cũ vẫn có polling dự phòng; không tự chạy mục còn lưu trong hàng đợi thủ công.
- Heartbeat gửi capacity và xác nhận snapshot hàng chờ; danh sách không đổi không phải gửi lại. Giữ nhịp heartbeat khoảng 30 giây.
- Báo tiến độ khoảng 15 giây trên server hỗ trợ; đổi phase/kết thúc/hủy gửi ngay. Giữ bảo vệ lease, fencing và kiểm tra hủy ở cả hai slot.
- Phân loại tín hiệu job/hủy/xóa file. JWT Realtime vẫn hạn 5 phút, được gia hạn khoảng mỗi 4 phút trên kết nối hiện có khi server hỗ trợ.
- Giữ các tính năng media của v1.14.20; không đổi engine/AI/FFmpeg, không tự tải model hoặc tài nguyên.

## Cập nhật

Dừng tác vụ/Agent, đóng app cũ trước khi cài Windows x64. Kiểm tra phiên bản **1.14.21** rồi bật lại Agent. Không tự cài hoặc restart VPS. Website cần migration `20261111120000_agent_efficient_sync.sql` và server mới (operator đã xác nhận triển khai); server cũ vẫn chạy chế độ dự phòng.
