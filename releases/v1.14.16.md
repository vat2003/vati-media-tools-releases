# VATI Media Tools v1.14.16 — VPS Loop lưu thẳng vào thư mục đích

## Thay đổi

- **Không tự tạo thư mục con theo job ID**. File loop nằm trực tiếp trong output folder, ví dụ `D:\VATI Loop Output\video_loop_010000.mp4`.
- Nếu bạn chủ động nhập Thư mục con trên Web, Tool vẫn dùng thư mục đó. Để trống để lưu thẳng trong output root.
- Hai link chạy song song giữ chỗ tên output trước khi file tồn tại. Nếu trùng tên, tự thêm số như `_1`, `_2`, không ghi đè hoặc xóa output của job khác.
- File và thư mục job từ bản trước không bị di chuyển hoặc xóa. Tự chọn ổ, loại trừ ổ và hủy từng job giữ nguyên.

## Cập nhật

Dừng agent/batch, đóng app cũ và cài trên VPS đang chạy Tool. Giữ URL/token. Sau cài đặt, kiểm tra phiên bản **1.14.16** rồi mở lại app hoặc khởi động lại scheduled task headless.

Không cần migration database, deploy Web hoặc tạo lại job. Job chạy sau khi cập nhật agent sẽ dùng cách lưu mới; output cũ vẫn ở chỗ cũ.
